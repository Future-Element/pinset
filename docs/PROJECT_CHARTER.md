# Pinset 项目章程

更新日期：2026-07-28

## 1. 问题

多语言开发者往往同时使用 fnm/nvm 管理 Node.js、uv/pyenv 管理 Python、FVM 管理 Flutter。每种工具都有不同的配置文件、安装路径、Shell 初始化、Windows 权限要求和项目切换语义。结果不是“命令多记几个”这么简单，而是：

- 同一个项目在不同操作系统上选择了不同版本；
- 多个管理器共同修改 PATH，`node`、`python` 或 `flutter` 的真实来源不透明；
- CI、本地终端和 IDE 使用的 SDK 不一致；
- 下载来源、校验方式和旧版本复现信息分散；
- 迁移到新工具时，用户不知道哪些配置可以保留、哪些环境会被破坏。

## 2. 目标用户

首要用户是同时维护 Node.js、Python 和 Flutter 项目的个人开发者与小型团队，尤其是：

- 在 Windows、macOS、Linux 间切换；
- 一个仓库或相邻仓库使用多种运行时；
- 已安装一个或多个旧版本管理器；
- 需要离线缓存、镜像或可审计安装来源；
- 希望工具在登录、云服务和遥测之外仍完整可用。

首版不以大型企业集中管控、容器镜像编排或通用语言插件生态为主要用户场景。

## 3. 产品定位

**Pinset 是一个本地优先、跨平台、可验证的项目运行时管理器。**

它的竞争优势不是支持最多工具，而是：

- 对 Node.js、CPython、Flutter 做内置且经过认证的高质量适配；
- 从 v0.1 起提供稳定锁文件；
- 项目配置只描述版本，不执行项目代码、钩子或任务；
- 在 Windows 上不依赖管理员权限来完成日常版本选择；
- 用 `doctor` 解释 PATH、旧管理器、配置优先级和实际可执行文件；
- 镜像和离线缓存不能绕过上游校验。

## 4. 产品原则

1. **本地优先**：不登录、不联网也能使用已经安装和缓存的运行时。
2. **数据而非代码**：读取项目配置不得执行任意脚本。
3. **显式变更**：不静默修改 Shell 配置、IDE 配置或删除旧管理器。
4. **可恢复**：安装、卸载和配置写入采用事务式操作，失败后可安全重试。
5. **来源可追踪**：版本、产物、哈希、签名/证明和提供方写入锁文件。
6. **检测多个，只激活一个**：共存可以被观察，但命令解析必须有唯一结果。
7. **范围克制**：运行时管理与依赖管理分离；uv、pnpm、Flutter pub 仍是互补工具。

## 5. 首版目标

- 一套 CLI 在认证平台上安装并选择 Node.js、CPython 和 Flutter；
- 项目根目录的 `pinset.toml` 与 `pinset.lock` 可以提交到版本库；
- 在子目录中运行命令时，稳定找到最近的项目配置；
- `pinset install --locked` 在锁文件不匹配时失败，而不是偷偷更新；
- `pinset doctor` 能解释命令来源及常见管理器冲突；
- 下载校验失败、解压异常、中断或并发安装都不会暴露部分安装；
- CI 可用 `pinset exec` 或锁定安装获得确定性行为。

## 6. 非目标

- 管理 JavaScript、Python、Dart/Flutter 包依赖；
- 自动创建 Python 虚拟环境；
- 充当任务运行器、环境变量管理器或 Secret Vault；
- 在 v0.1 提供第三方插件、脚本钩子或远程代码执行；
- 自动修改 `.vscode`、Android Studio、Xcode 或系统级 SDK 配置；
- 云端账号、团队同步、遥测、广告或数据销售；
- 第一版就覆盖所有语言、CPU 架构和历史版本。

## 7. 成功标准

技术指标：

- 认证矩阵中每个运行时至少有一个版本通过真实产物端到端安装与执行；
- 热路径命令选择不访问网络；
- shim 额外路由开销候选目标为 p95 不超过 10 ms（需以认证硬件实测冻结）；
- 所有安装都验证校验信息，锁文件序列化确定；
- 中断恢复、错误压缩包和并发安装测试全部通过。

用户指标：

- 5–8 位目标用户可在 5 分钟内完成安装、初始化和一次项目切换；
- 用户能通过 `current`/`which` 准确回答“现在到底用了哪个版本、为什么”；
- 从旧管理器迁移时，`doctor` 能在不破坏原环境的前提下给出可执行建议；
- 8–12 次访谈中确认“冲突诊断 + 可复现安装”具有实际价值，而不只是命令统一带来的轻微便利。

## 8. 立项门槛

在进入完整开发前，必须通过以下验证：

- Rust 多调用 shim 在三大平台上的正确性和性能；
- 三种运行时各完成一次真实下载、校验、解压、执行；
- Flutter SDK 在 VS Code/Android Studio 场景下有可接受的稳定目录方案；
- Python 可分发包的清单、许可证和来源固定方案可审计；
- 已安装旧管理器的机器上，Pinset 可以诊断且不会抢占不相关命令。
